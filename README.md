# C-Project-1--Address-Book
Description:
A console-based C application to manage contacts. It allows you to add, search, update, and delete contact details (names, phone numbers, and email addresses) with persistent storage in a CSV file.

Features :
1. Add new contacts
2. Search contacts by name
3. Edit/update contact information
4. Delete contacts
5. List all contacts
6. Persistent storage using contacts.csv
7. Input validation for phone numbers and emails
